# Simplify Algebraic Expression

- **Topic:** #hash-map #string #parsing #parentheses
- **Updated:** Oct 15, 2026
- 문제 번호가 없는 기술 면접 문제.

## 문제

변수, `+`, `-`, 괄호로 이루어진 문자열을 받아 **괄호를 풀고 같은 변수의 계수를 합친 식**을 반환한다. 괄호는 최대 한 단계이며, 여러 괄호 그룹이 나란히 나오는 것은 가능하다.

```text
입력: a+b+a+c-b-b-b+(d+c)
출력: 2a-2b+2c+d
```

이 풀이에서는 다음을 가정한다. 면접에서 조건이 명확하지 않다면 먼저 확인한다.

- 변수는 한 글자이고, 입력에는 `2a` 같은 숫자 계수가 없다.
- 문법이 올바른 식이며 공백은 무시한다. 식이나 그룹 시작의 단항 부호(`-a`, `-(a+b)`)는 허용한다. `a--b`처럼 연속된 부호는 다루지 않는다.
- 출력 변수 순서는 **입력에서 처음 등장한 순서**로 유지한다.
- 계수가 `0`인 항은 생략하고, `1a`는 `a`, `-1a`는 `-a`로 쓴다. 모든 항이 사라지면 `"0"`을 반환한다.

## 풀이: 변수별 계수 + 두 가지 부호

각 변수의 값을 계산하는 문제가 아니다. 변수마다 `+1` 또는 `-1`을 누적하여 동류항을 합치는 문제다.

```text
a + b + a + c - b - b - b + (d + c)

a: +1 +1       =  2
b: +1 -1 -1 -1 = -2
c: +1 +1       =  2
d: +1          =  1
```

괄호 앞이 `-`이면 **괄호 안의 모든 항**에 부호 반전이 적용된다.

```text
a-(b-c) = a-b+c
```

따라서 다음 상태를 따로 관리한다.

| 상태 | 의미 | 초기값 |
| --- | --- | --- |
| `coefficients[ch]` | 지금까지 읽은 변수 `ch`의 계수 합 | 해당 변수 첫 등장 시 `0` |
| `sign` | 현재 그룹 안에서 다음 항에 적용할 부호 | `1` |
| `group_sign` | 괄호 앞의 부호. 괄호 밖에서는 `1` | `1` |

변수를 만나면 실제 기여분은 **`sign * group_sign`**이다.

### 문자별 처리

1. `+`: `sign = 1`.
2. `-`: `sign = -1`.
3. `(`: 직전 부호를 `group_sign`에 저장하고, 그룹 안의 첫 항을 위해 `sign = 1`로 초기화한다.
4. `)`: 그룹을 벗어났으므로 `group_sign = 1`, `sign = 1`로 초기화한다.
5. 변수: `coefficients[ch] += sign * group_sign`.

괄호가 한 단계뿐이므로 그룹 부호 하나만 있으면 된다. 중첩 괄호까지 허용하면 바깥 부호를 복원할 수 있도록 스택을 사용해야 한다.

## Python 코드

```python
def simplify(expression: str) -> str:
    coefficients = {}
    sign = 1
    group_sign = 1

    for ch in expression:
        if ch.isspace():
            continue

        if ch == "+":
            sign = 1
        elif ch == "-":
            sign = -1
        elif ch == "(":
            group_sign = sign
            sign = 1
        elif ch == ")":
            group_sign = 1
            sign = 1
        else:  # 유효한 입력이므로 나머지는 한 글자 변수다.
            coefficients[ch] = (
                coefficients.get(ch, 0) + sign * group_sign
            )

    result = []

    # Python dict는 삽입 순서를 유지한다.
    for variable, coefficient in coefficients.items():
        if coefficient == 0:
            continue

        if coefficient < 0:
            result.append("-")
        elif result:
            result.append("+")

        magnitude = abs(coefficient)
        if magnitude != 1:
            result.append(str(magnitude))

        result.append(variable)

    return "".join(result) or "0"
```

## 부호 추적: `a-(b-c)+b`

아래 표의 상태는 각 문자를 처리한 **직후**다.

| 문자 | `sign` | `group_sign` | 변수 계수 변경 |
| --- | --- | --- | --- |
| `a` | `1` | `1` | `a += 1` |
| `-` | `-1` | `1` | — |
| `(` | `1` | `-1` | — |
| `b` | `1` | `-1` | `b += -1` |
| `-` | `-1` | `-1` | — |
| `c` | `-1` | `-1` | `c += 1` |
| `)` | `1` | `1` | — |
| `+` | `1` | `1` | — |
| `b` | `1` | `1` | `b += 1` |

최종 계수는 `a: 1, b: 0, c: 1`이므로 결과는 `"a+c"`다.

## 왜 올바른가?

각 변수를 읽을 때 괄호 밖에서는 `group_sign = 1`이므로 직전 연산자의 부호가 그대로 적용된다. 괄호 안에서는 괄호 앞의 부호와 내부 연산자의 부호를 곱하므로 분배법칙과 같은 결과를 얻는다. 특히 `-(-c)`에 해당하는 항은 `(-1) * (-1) = 1`이 된다.

딕셔너리는 처리한 모든 항의 계수 합을 변수별로 유지한다. 같은 변수의 항은 합쳐도 식의 값이 변하지 않으므로, 마지막에 계수가 0인 항을 제외하고 출력하면 원래 식과 동치인 식이 된다.

## 확인할 예시

| 입력 | 출력 | 확인할 점 |
| --- | --- | --- |
| `a+b+a+c-b-b-b+(d+c)` | `2a-2b+2c+d` | 계수 합산 |
| `a-(b-c)+b` | `a+c` | 괄호 안의 마이너스도 반전 |
| `a-a` | `0` | 모든 항이 상쇄됨 |
| `-(a+b)+c` | `-a-b+c` | 첫 항이 음수 |
| `a-(b+c)-(d-a)` | `2a-b-c-d` | 여러 괄호 그룹 |
| `b+a+b` | `2b+a` | 첫 등장 순서 유지 |
| ` a - ( b - c ) ` | `a-b+c` | 공백 무시 |

## 복잡도

문자열 길이를 `n`, 서로 다른 변수 수를 `k`라고 하자.

- 시간: 평균적인 딕셔너리 연산을 가정하면 **O(n)**. 입력을 한 번 읽고, 마지막에 변수별 결과를 만든다. 출력 길이도 O(n)이다.
- 보조 공간: 계수 딕셔너리는 **O(k)**. 출력용 리스트와 반환 문자열까지 포함하면 **O(k + L)**이며, `L`은 결과 문자열 길이다.
- 변수가 영문 소문자 26개로 고정되면 계수 저장 공간은 O(1)이다.
- 사전순 출력을 요구하면 마지막에 키를 정렬하므로 일반적인 `k`에 대해 O(k log k)가 추가된다.

## 헷갈린 지점 / 기억할 것

- `sign` 하나만 쓰면 괄호 안의 `+`, `-`를 읽을 때 괄호 앞의 부호를 잃는다. **항의 부호와 그룹의 부호를 분리한다.**
- `(`에서 `group_sign = sign`을 한 뒤 반드시 `sign = 1`로 바꾼다. 그렇지 않으면 `-(a+b)`의 첫 `a`에 음수를 두 번 적용하여 양수로 만든다.
- `)`에서는 그룹 부호를 초기화한다. 그렇지 않으면 괄호 뒤의 항도 이전 그룹의 영향을 받는다.
- 딕셔너리에서 계수가 0인 변수를 바로 삭제하지 않는다. 이후 다시 등장하면 삽입 순서가 바뀔 수 있다. 마지막 출력 단계에서만 건너뛴다.
- 양수 항 앞의 `+`는 이미 출력한 항이 있을 때만 붙인다. 계수 `1`, `-1`, `0`의 출력도 따로 처리한다.
- 이 코드는 한 단계 괄호용이다. 중첩 괄호, 여러 글자 변수, 입력 숫자 계수는 별도의 확장 문제다.

## 면접에서 설명할 문장

> 식을 한 번 순회하면서 변수별 계수를 딕셔너리에 누적합니다. 항 자체의 부호와 괄호 앞의 부호를 따로 저장하고, 변수를 만나면 두 부호를 곱해 더합니다. 괄호가 한 단계라 스택 없이 처리할 수 있고, 마지막에 0이 아닌 계수만 형식에 맞게 출력합니다. 시간은 O(n), 계수 저장 공간은 O(k)입니다.
