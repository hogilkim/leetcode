# 962. Maximum Width Ramp

- **Problem:** [LeetCode](https://leetcode.com/problems/maximum-width-ramp/)
- **Solution:** [[../962. Maximum Width Ramp.py]]
- **Topic:** #MonotonicStack
- **Updated:** Oct 9, 2026

## 문제

배열에서 `i < j`이고 `nums[i] <= nums[j]`인 두 인덱스의 최대 거리 `j - i`를 구한다. 없으면 `0`을 반환한다. 중간 원소는 어떤 값이어도 된다.

예: `[6, 0, 8, 2, 1, 5]` → `i = 1`, `j = 5` → 너비 `4`.

## 풀이 / 기억할 것

- **단조 감소 스택에 왼쪽 끝점 후보의 인덱스를 저장한다.** 왼쪽부터 보며 이전 최솟값보다 작은 값만 넣는다. 앞에 더 작거나 같은 값이 있으면 그 인덱스가 더 넓은 너비를 만들 수 있으므로 현재 인덱스는 필요 없다.
- 오른쪽 끝점 `j`는 **오른쪽부터 왼쪽으로** 탐색한다. `nums[stack[-1]] <= nums[j]`인 동안 `i`를 pop하고 `j - i`로 최댓값을 갱신한다.
- **pop해도 되는 이유:** 해당 `i`와 연결 가능한 가장 오른쪽 `j`를 이미 찾았다. 이후 `j`는 더 작아지므로 너비가 커질 수 없다.
- 스택에는 값이 아닌 **인덱스**를 저장한다. 스택을 만들 때는 `>`, ramp를 확인할 때는 같은 값도 허용하므로 `<=`를 쓴다. 다시 풀기.

각 인덱스는 최대 한 번 push/pop하므로 시간 `O(n)`, 공간 `O(n)`.
