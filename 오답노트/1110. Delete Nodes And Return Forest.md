# 1110. Delete Nodes And Return Forest

- **Solution:** [[../1110. Delete Nodes And Return Forest.py]]
- **Topic:** #DFS #BinaryTree
- **Last attempt:** Oct 6, 2026 (1110-2)

## Question

- Delete every node whose value is in `to_delete` from a binary tree. Return the roots of the remaining separate trees (the forest).

## Technique

- Convert `to_delete` to a set for fast lookup, then use **DFS with a flag indicating whether a node could be a new root**. Start with the original root's flag set to `True`.
- If a node is deleted, disconnect it from its parent and explore both children with the flag set to `True`. **Keep exploring: a child may also need to be deleted.**
- If a node survives and the flag is `True`, add it to the result. Explore its children with the flag set to `False`, since they still have a parent.
- Time: `O(n + d)`. Extra space: `O(h + d)` excluding the output, where `d` is the number of deletion values and `h` is the tree height.
