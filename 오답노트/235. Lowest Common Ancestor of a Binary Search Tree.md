## 문제

이진 탐색 트리에서 두 노드 `p`, `q`의 가장 깊은 공통 조상(LCA)을 찾는다. 노드 자신도 조상으로 인정한다.

## 기억할 것

- Use the BST property, not generic-tree DFS: if both `p` and `q` are smaller than `root`, go left; if both are larger, go right; otherwise `root` is the LCA (the split point).
