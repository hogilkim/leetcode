# 694. Number of Distinct Islands

## 문제

`1`은 땅, `0`은 물인 격자에서 상하좌우로 연결된 섬의 서로 다른 모양 개수를 구한다. 위치만 옮겨 같아지는 섬은 같은 모양이고, 회전이나 반사는 허용하지 않는다.

## 풀이

- **DFS + 모양을 저장하는 set:** 방문하지 않은 땅에서 DFS를 시작하고, 모든 섬에 동일한 방향 순서로 탐색한다.
- 이동 방향과 복귀 표시 `"b"`를 문자열로 기록하면 위치와 무관한 모양 표현이 된다. 방문한 칸은 다시 탐색하지 않는다.
- 각 섬의 문자열을 set에 넣고 `len(set)`을 반환한다. 같은 모양은 같은 문자열이므로 중복을 제거할 수 있다.

## 기억할 것

- `return new_shape + "b"`의 `"b"`는 현재 셀의 탐색이 끝나 부모 셀로 돌아가는 **backtracking 표시**다.

## 왜

- 방향만 기록하면 `아래 → 오른쪽`과 `아래 → 부모로 복귀 → 오른쪽`이 같은 문자열이 되어 서로 다른 섬을 구분하지 못한다.
- 예: `[[1, 0], [1, 1]]`과 `[[1, 1], [1, 0]]`은 내 방향 사전에서 둘 다 `"lr"`이지만, `"b"`를 넣으면 각각 `"lrbbb"`, `"lbrbb"`가 된다. **어디서 복귀했는지까지 기록해야 가지 구조를 보존할 수 있다.**
