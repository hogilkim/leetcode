## 문제

문자열 `s`의 부분 수열(subsequence)인 `words`의 단어 개수를 구한다. 부분 수열은 문자를 건너뛸 수 있지만 순서는 유지해야 한다. 예: `s = "abcde"`, `words = ["a", "bb", "acd", "ace"]`이면 답은 `3`이다.

## 풀이

- **해시맵 + 대기 버킷:** 각 단어의 남은 문자열을 **다음에 필요한 문자**별로 묶는다.
- `s`를 왼쪽부터 읽으며 현재 문자 버킷을 꺼내 비운다. 해당 단어들만 한 글자씩 진행시켜 다음 문자 버킷으로 옮긴다. 남은 길이가 `1`이면 단어가 완성되므로 개수를 더한다.
- 가장 먼저 만나는 필요한 문자를 사용해도 이후 문자를 고를 공간이 최대한 남는다. 따라서 순서를 유지하며 모든 부분 수열을 찾는다.
- 현재 코드의 시간 복잡도는 문자열 슬라이싱 때문에 최악 `O(n + Σ|word|²)`, 추가 공간은 `O(m + L)`이다. `n = len(s)`, `m = len(words)`, `L = Σ|word|`. 남은 문자열 대신 `(word, index)`를 저장하면 시간 `O(n + L)`, 추가 공간 `O(m)`으로 개선할 수 있다.

## 기억할 것

- **현재 버킷을 먼저 분리하고 비운 뒤 처리한다.** `"aa"`처럼 다음 문자도 같을 때, 다시 넣은 항목은 `s`의 다음 문자에서 처리해야 한다.
- 현재 코드의 `.copy()` + `del`은 이를 보장한다. `waiting = hashmap[char]; hashmap[char] = []`로도 분리할 수 있다.
- 같은 단어가 여러 번 나오면 각각 세어야 한다. `set`으로 중복을 제거하지 않는다.
