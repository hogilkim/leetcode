## 문제

정수 값을 저장하는 스택을 구현한다. `push(value)`로 값을 넣고, `pop()`으로 맨 위 값을 제거하며, `top()`으로 맨 위 값, `getMin()`으로 현재 스택의 최솟값을 조회한다. 모든 연산은 `O(1)`이어야 한다.

`pop`, `top`, `getMin`은 스택이 비어 있지 않을 때만 호출된다.

## 풀이

**값을 저장하는 `stack`과 각 깊이까지의 최솟값을 저장하는 `minstack`을 함께 관리한다.**

- `stack[i]`: i번째로 쌓인 값.
- `minstack[i]`: `stack[0:i + 1]`의 최솟값.
- 두 스택의 길이는 항상 같다.

`push(value)`에서는 값을 넣고, 기존 최솟값과 새 값 중 작은 값도 함께 넣는다. 첫 값이면 그 값 자체가 최솟값이다.

```python
self.stack.append(value)
minval = min(self.minstack[-1] if self.minstack else value, value)
self.minstack.append(minval)
```

`pop()`에서는 두 스택을 모두 한 번씩 pop한다. `top()`은 `stack[-1]`, `getMin()`은 `minstack[-1]`을 반환한다.

### 진행 예시

| 연산 | stack | minstack | 현재 최솟값 |
|---|---|---|---|
| `push(-2)` | `[-2]` | `[-2]` | `-2` |
| `push(0)` | `[-2, 0]` | `[-2, -2]` | `-2` |
| `push(-3)` | `[-2, 0, -3]` | `[-2, -2, -3]` | `-3` |
| `pop()` | `[-2, 0]` | `[-2, -2]` | `-2` |

마지막 pop 이후 `top()`은 `0`, `getMin()`은 `-2`이다.

### 복잡도

- 각 연산의 시간: `O(1)`. Python 리스트의 끝에 추가·제거하는 비용은 분할 상환 기준이다.
- 공간: 원소가 n개일 때 `O(n)`. 각 깊이의 최솟값을 하나씩 저장한다.

## 왜

현재 최솟값 하나만 변수로 저장하면 그 값이 pop된 뒤의 최솟값을 알 수 없다. 매 깊이의 최솟값을 함께 기록하면 pop할 때 **한 단계 전의 최솟값이 자동으로 드러난다.** 전체 스택을 다시 탐색할 필요가 없다.

## 기억할 것 / 헷갈린 지점

- **이번 155-2 풀이의 핵심 로직은 맞다.** 복습할 부분은 두 스택의 길이를 유지하는 규칙과 최솟값의 복원 원리다.
- 최솟값이 바뀌지 않아도 `minstack`에 넣는다. 예를 들어 `push(3)`, `push(5)`이면 `minstack`은 `[3, 3]`이다. 그래야 두 스택에서 함께 pop할 수 있다.
- 중복 최솟값도 깊이마다 저장한다. `push(2)`, `push(2)`, `pop()` 이후에도 `getMin()`은 `2`이다.
- `minstack`에는 인덱스가 아닌 **최솟값 자체**를 저장한다.
- `getMin()`마다 `min(stack)`을 호출하면 조회가 `O(n)`이 되어 조건을 만족하지 못한다.
- **기억할 한 문장: 값 하나를 넣을 때 그 깊이의 최솟값도 넣고, 뺄 때는 둘 다 뺀다.**
