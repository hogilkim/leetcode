## 문제

중복 없는 오름차순 배열을 회전한 `nums`에서 최솟값을 찾는다. 예: `[3, 4, 5, 1, 2]` → `1`.

## 풀이

- **이진 탐색:** 현재 풀이에서 `nums[l] <= nums[r]`이면 남은 구간이 정렬되어 있으므로 `nums[l]`이 최솟값이다.
- 그렇지 않을 때 `nums[l] <= nums[mid]`이면 왼쪽 절반이 정렬되어 있으므로 최솟값은 오른쪽에 있다: `l = mid + 1`.
- 왼쪽 절반이 정렬되어 있지 않으면 최솟값은 `[l, mid]`에 있다: `r = mid`. `mid`가 최솟값일 수 있으므로 유지한다. 시간 `O(log n)`, 공간 `O(1)`.

## 기억할 것

- Be careful with the `if` conditions for binary search.
