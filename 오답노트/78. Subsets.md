## 기억할 것

- Base case: `if i >= len(nums): res.append(subset.copy()); return` — every index has been decided (include / skip), so the current `subset` is one complete answer.

## 왜

- Each call decides one index `i`. Once `i` runs past the end there is nothing left to decide, so that path is a finished subset — that is the only moment to record it.
- `subset.copy()` is required: `subset` keeps being mutated by `append` / `pop` afterwards, so appending the reference would make every entry in `res` the same (empty) list at the end.

```python
def backtracking(i, subset):
    if i >= len(nums):          # all indices decided
        res.append(subset.copy())
        return
    backtracking(i + 1, subset) # skip nums[i]
    subset.append(nums[i])
    backtracking(i + 1, subset) # take nums[i]
    subset.pop()
```

## 틀린 지점 / 헷갈린 지점

- Couldn't place the result-append. It goes in the base case (`i >= len(nums)`), not after each decision — the 2^n leaves of the decision tree are exactly the 2^n subsets.
