## What I missed: what does bipartite mean?

- Split the nodes into two teams: **neighbors connected by an edge must be on different teams.** Check whether every connection can follow this rule.

## Solving technique

- **Use BFS to assign alternating teams.** Store `0` for unassigned nodes and `1` / `-1` for the two teams.
- Assign each unassigned neighbor to `-teams[node]` and enqueue it. If a neighbor is already on the same team, return `False`.
- The graph may be disconnected, so loop over all nodes and start BFS from each unassigned node. Return `True` if no conflict occurs.
- Time: `O(V + E)`. Space: `O(V)`.
