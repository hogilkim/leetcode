## 문제

한 문장에 연속된 단어 묶음을 한 번 삽입해서 다른 문장과 같게 만들 수 있는지 반환한다. 삽입할 묶음은 비어 있어도 되고, 문장 맨 앞이나 맨 뒤에 넣어도 된다. 기존 단어를 삭제하거나 바꿀 수는 없다.

## 풀이

문장을 단어 배열로 나누고 `words1`을 더 긴 문장으로 둔다. 앞에서 일치하는 단어 수를 `start`, 뒤에서 일치하는 단어 수를 `end`로 센다. 짧은 문장의 길이 `n2`에 대해 `start + end >= n2`이면 `True`다.

```python
class Solution:
    def areSentencesSimilar(self, sentence1: str, sentence2: str) -> bool:
        words1 = sentence1.split()
        words2 = sentence2.split()

        if len(words1) < len(words2):
            words1, words2 = words2, words1

        start, end = 0, 0
        n1, n2 = len(words1), len(words2)

        while start < n2 and words1[start] == words2[start]:
            start += 1

        while end < n2 and words1[n1 - end - 1] == words2[n2 - end - 1]:
            end += 1

        # 짧은 문장의 모든 단어가 일치하는 앞부분 또는 뒷부분에 포함되는가?
        return start + end >= n2
```

두 입력 문자열의 전체 문자 수를 `L`이라 하면, `split()`까지 포함한 시간과 추가 공간은 모두 `O(L)`이다.

## 왜: `start + end >= n2`

핵심은 **짧은 문장의 모든 단어가 일치하는 앞부분 또는 뒷부분으로 덮이는가?**다. `start`와 `end`는 인덱스가 아니라 일치한 **단어 수**다.

```text
긴 문장:   My | name is | Haley
짧은 문장: My |         | Haley
           앞 1개        뒤 1개

start = 1, end = 1, n2 = 2
1 + 1 >= 2 → True
```

짧은 문장의 모든 단어가 맞으므로, 긴 문장에만 있는 `"name is"`를 두 일치 구간 사이에 삽입하면 된다. 일치하는 앞부분과 뒷부분 사이에 남는 긴 문장의 단어들은 하나의 연속된 묶음이다.

반대로 짧은 문장에 덮이지 않은 단어가 있으면 삽입만으로 해결할 수 없다.

```text
긴 문장:   My | name is | Haley
짧은 문장: My | dog     | Haley

start = 1, end = 1, n2 = 3
1 + 1 < 3 → False
```

짧은 문장의 `"dog"`가 맞지 않는다. 단어를 삽입해도 기존의 `"dog"`를 지우거나 바꿀 수 없다.

### 왜 `==`가 아니라 `>=`인가?

두 반복문은 독립적으로 실행되므로 같은 단어를 앞에서도, 뒤에서도 셀 수 있다.

```text
긴 문장:   A B C
짧은 문장: A B C

start = 3, end = 3, n2 = 3
start + end = 6 >= 3 → True
```

앞에서 덮은 구간과 뒤에서 덮은 구간이 겹쳐도 괜찮다. 합이 `n2` 이상이면 두 구간 사이에 덮이지 않은 짧은 문장의 단어가 없다는 뜻이다. 이 경우 짧은 문장을 앞에서 `start`개, 뒤에서 `n2 - start`개로 나눠 생각하면, 겹침 없이 모든 단어를 대응시킬 수 있다.

## 기억할 것

- 긴 문장 = 일치하는 앞부분 + 삽입할 한 묶음 + 일치하는 뒷부분.
- 짧은 문장 = 일치하는 앞부분 + 일치하는 뒷부분.
- `start + end >= n2`는 **짧은 문장의 모든 단어를 일치 구간으로 덮었는지** 확인한다.
- 삽입 위치는 맨 앞/맨 뒤도 가능하다. `start`나 `end`가 0이어도 된다.
- 일반적인 부분 수열인지 확인하는 것만으로는 부족하다. `"A B C D"`와 `"A C"`는 `"B"`, `"D"`를 두 곳에 삽입해야 하므로 `False`다.
- 아직 직접 해결하지 않았으므로 코드 없이 다시 풀어 보기.

## 틀린 지점 / 헷갈린 지점

- 마지막 조건이 왜 긴 문장의 남는 부분을 한 묶음으로 삽입할 수 있다는 뜻인지 이해하기 어려웠다.
- “가운데에 남는 단어가 있는가?”보다 “짧은 문장에 맞지 않는 단어가 남았는가?”로 생각하면 이해하기 쉽다.
- 다른 포인터 풀이도 살펴봤지만, 복습할 풀이는 위의 첫 번째 `start` / `end` 카운트 방식이다.
