## 문제

격자에서 `-1`은 벽, `0`은 문, `INF`는 빈 방이다. 상하좌우로 이동해 각 빈 방을 가장 가까운 문까지의 거리로 채운다. 문에 도달할 수 없는 방은 `INF`로 유지한다.

## 기억할 것

- Be careful with adding duplicate coordinates to the queue in BFS. Mark a cell as visited (write its distance) at the moment you enqueue it, not when you pop it.
- I need to solve this again.

## 왜

- If you only mark on pop, two neighbors can both push the same `INF` cell before either of them is popped, so the cell enters the queue twice and gets processed twice.
- Writing `rooms[nr][nc] = distance + 1` right before `queue.append((nr, nc))` makes the `rooms[nr][nc] == INF` check reject the cell the second time.

```python
if 0 <= nr < ROW and 0 <= nc < COL and rooms[nr][nc] == INF:
    rooms[nr][nc] = distance + 1   # visited, before enqueue
    queue.append((nr, nc))
```

## 틀린 지점 / 헷갈린 지점

- Multi-source BFS: every gate (`0`) goes into the queue up front, then a single BFS gives the nearest-gate distance for every room.
