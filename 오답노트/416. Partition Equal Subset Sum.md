## 문제

양의 정수 배열을 합이 같은 두 부분집합으로 나눌 수 있는지 반환한다. 모든 원소를 정확히 한쪽에 배정해야 한다.

## 기억할 것

- 백트래킹 대신 **부분합 DP (0/1 Knapsack)**: 합이 `sum(nums) // 2`인 부분집합을 찾는다. 전체 합이 홀수면 불가능하다.
- `dp = {0}`에서 시작해 각 `num`마다 `next_dp = dp | {s + num for s in dp}`로 가능한 합을 갱신한다. `target`이 포함되면 `True`.
- 같은 합을 만드는 여러 경로를 하나로 합쳐 중복 탐색을 줄인다. 이전 `dp`로 다음 집합을 만들어야 각 숫자를 한 번만 사용한다.
