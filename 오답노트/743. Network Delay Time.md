## Question

- A signal starts at node `k`. Given directed edges with travel times, find how long it takes to reach all `n` nodes. Return `-1` if any node is unreachable.

## Technique

- Find the **shortest travel time from `k` to every node**. The answer is the **maximum of those shortest times**, since the last node determines when everyone has received the signal.
- Use **Dijkstra with a min-heap**: start with `dist[k] = 0` and all others at infinity. Pop the smallest time, skip outdated entries, and update a neighbor only when `time + weight < dist[neighbor]`.
- My solution uses a regular queue and re-enqueues nodes whenever their distance improves. This is repeated relaxation, not ordinary BFS: weighted edges mean the first visit may not give the shortest path.
- Return `-1` if any distance remains infinity; otherwise return `max(dist[1:])`.
